Hatch list/ipv6 set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/hatchipv6/

## Install / run

```bash
git clone https://github.com/theworker02/hatchipv6.git
cd hatchipv6
node src/cli.js
node --test
```
